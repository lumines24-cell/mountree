# 平台与规格

> 当前 Higgsfield 批量执行默认使用 15 秒。每条仍是一个连续镜头、一个主要视觉任务、一个主运镜：前 3–6 秒完成任务，余下时间保持同一稳定构图或自然停留，不新增第二个动作、产品状态或镜头。

```yaml
id: spec_higgsfield_15s_vertical
type: delivery_spec
text: Vertical 9:16, 15-second single continuous shot; complete one visible shoe or outfit task in the first 3–6 seconds, then hold the same stable end composition with no second action, product state or camera angle.
platform: [higgsfield, tiktok, reels, shorts]
status: default_current
```

```yaml
id: spec_tiktok_reels_short
type: delivery_spec
text: Vertical 9:16, 5–8 second single continuous shot; show action or shoe silhouette in the first second.
platform: [tiktok, reels, shorts]
```

```yaml
id: spec_tiktok_reels_10s_concept
type: delivery_spec
text: Vertical 9:16, 10-second single continuous conceptual fashion shot; show the worn shoe silhouette in the first second and complete the visual turn by the final second.
platform: [tiktok, reels, shorts]
status: concept_only
source: [time_pause_commute_visual_narrative]
```

```yaml
id: spec_tiktok_test
type: test_rule
text: Test scene, opening action and camera before testing copy; optimize for first-second hold and completion.
platform: [tiktok]
```

```yaml
id: spec_reels_cover
type: test_rule
text: Hold one clean full-outfit or shoe-profile frame for a readable cover and save-worthy result.
platform: [reels]
```

```yaml
id: spec_pinterest_vertical
type: delivery_spec
text: Vertical composition with a clear outfit-and-scene relationship and enough negative space for later copy.
platform: [pinterest]
```

```yaml
id: spec_product_page
type: delivery_spec
text: Use real product detail and no generated parameter text; validate against the current platform image rules before publishing.
platform: [shopify, amazon]
```
