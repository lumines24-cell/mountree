## 两种组合方式

### 视频：5–8 秒单镜头

```text
[FORMAT / PLATFORM]
[PRODUCT REFERENCE + VERIFIED DETAIL]
[PERSONA + OUTFIT]
[SCENE + TIME]
[HOOK / CONTENT INTENT]
[ONE ACTION + ONE PRODUCT MOMENT]
[CAMERA + COMPOSITION]
[LIGHT / ART DIRECTION + SOUND]
[OPTIONAL SPOKEN LINE]
[CONSTRAINTS / NEGATIVE]
```

### 图片：一张图只讲一个时刻

```text
[FORMAT / PLATFORM]
[PRODUCT REFERENCE + VERIFIED DETAIL]
[PERSONA OR HANDS-ONLY]
[SCENE / SURFACE]
[ONE PRODUCT MOMENT]
[CAMERA + COMPOSITION]
[LIGHT / ART DIRECTION]
[CONSTRAINTS / NEGATIVE]
```

## 维护规则

- 每条素材只归入一个“主库”；在成品脚本里用链接或编号引用，避免复制后失控。
- 产品事实、价格、性能、环保与认证只能填已核验内容；未确认时保留 `[待核验]`。
- 视频默认固定为 1 人、1 双鞋、1 个主动作、1 个连续镜头；图片默认 1 个画面重点。
- 每轮批量生成固定产品参考与人物，只替换一个变量，才知道哪个元素真正带来差异。
