# 产品事实与参考素材

> 这是所有生成内容的锚点。先放真实参考图，再选择一个画面中确实可见的细节；不要让模型补全未提供的结构或文案。

## 每个鞋款需要的最小素材包

| 素材 | 用途 | 必需 |
| --- | --- | --- |
| 正侧 45° 全鞋图 | 锁定鞋型、颜色、比例 | 是 |
| 上脚全身 / 小腿到脚 | 锁定穿着比例 | 是 |
| 鞋底图 | 鞋底、纹路、跟高展示 | 需要拍鞋底时 |
| 近景细节图 | 材质、鞋头、扣件等可见细节 | 建议 |
| 鞋盒 / 包装图 | 开箱、礼物内容 | 仅开箱 |
| 已核验事实卡 | 台词、字幕、商品页主张 | 是 |

## 可选的“一个可见细节”写法

- `the exact toe shape visible in the reference`
- `the side profile and heel height visible in the reference`
- `the material finish visible in natural window light`
- `the sole edge visible without distortion`
- `[one verified visible upper detail]`

## 产品事实卡模板

```yaml
产品名称:
SKU / 颜色:
可用参考图:
可见细节:
已核验舒适 / 材料主张:
不可使用的主张:
价格（如需出现）:
核验日期:
```

## 固定英文锚点

```text
Use the attached Mountree shoe reference as the authoritative visual source. Preserve the exact silhouette, toe shape, heel height, sole pattern, color, material finish and realistic scale.
```
