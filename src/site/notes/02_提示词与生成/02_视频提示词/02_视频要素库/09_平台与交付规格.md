# 平台与交付规格

| 用途 | 首选规格 | 素材重点 | 生成原则 |
| --- | --- | --- | --- |
| TikTok / Reels / Shorts | 9:16，5–8 秒单镜头 | 前 1 秒有动作或鞋型 | 原生、连续、轻微手持感 |
| Instagram Feed | 4:5 图片 / 9:16 Reels | 封面先读到鞋型与造型 | 画面干净、可保存 |
| Pinterest | 2:3 图片 / 9:16 视频 | 场景、穿搭、搜索意图 | 静态图优先留白与垂直构图 |
| Shopify / 商品页 | 1:1 / 4:5 图片 | 真实产品与可查细节 | 不用生成文字或参数 |
| Amazon 商品页 | 1:1 图片 | 产品占比、轮廓和细节 | 以当时平台图片规则为准 |

## 版本命名

```text
[日期]_[鞋款]_[内容目标]_[人物]_[场景]_[动作]_[平台]_v01
例如：20260723_BlackFlat_Silhouette_ProWoman_Elevator_Mirror_TT_v01
```

## 批量测试表字段

| 固定项 | 本轮只替换项 | 结果记录 |
| --- | --- | --- |
| 鞋款参考、人物、时长、平台 | 场景或动作或钩子其一 | 完播 / 收藏 / 点击 / 主观准确度 |

> 一次只替换一个变量；否则无法判断是场景、人物、动作还是文案起作用。
