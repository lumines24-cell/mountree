# 原子化生成协议

> 目的：不再一次生成“完整广告”。每一个叶子小类只生成一条 3–6 秒独立片段，且只承担一个视觉任务。生成合格后再剪辑，不让一个 Prompt 同时承担产品保真、人物身份、复杂动作、场景变化、台词与 CTA。

> **当前 Higgsfield 批量执行覆盖：** 生成界面固定为 15 秒时，叶子单元的视觉任务仍只发生一次并在前 3–6 秒完成；后续时间只能保持同一连续状态、自然呼吸或稳定停留。不得为了填满 15 秒增加第二动作、第二镜头、第二产品状态、台词、CTA 或场景变化。

## 唯一生产顺序

`内容路线 → 小类 → 叶子生成单元 → 单条 Prompt → 单条质检 → 已选片段 → 后期剪辑`。

不可跳过“叶子生成单元”和“单条质检”。任何 10–15 秒成片都必须由已验收的原子片段剪辑而成。

## 原子片段硬规则

| 字段 | 每条片段只允许 |
| --- | --- |
| 时长 | 3–6 秒；概念叙事最多 10 秒且必须有专属节拍卡 |
| 产品状态 | `上脚的一双`、`手持的一只`、`盒内的一双` 三选一 |
| 视觉任务 | 一个：完整轮廓、一个已核验细节、一次普通步伐、一次穿搭停留、一次环境变化 |
| 人物动作 | 一个连续动作；不得先手持再上脚，或开盒再拿鞋走路 |
| 镜头 | 一个景别、一个主运镜、一个结束构图 |
| 声音 | 一种环境声或一种拟音；默认无台词、无音乐 |
| 可变项 | 一个；A/B 测试时其余变量全部固定 |

## 每个叶子单元的输入卡

```yaml
unit_id: atomic_onfoot_side_profile
mode: I2V_or_R2V
duration_seconds: 4
reference_roles:
  product: '@Image1 exact product only; do not transfer scene, person or pose'
  identity: '@Image2 only when an authorized character reference exists'
product_state: product_state_worn_pair_only
visible_task: moment_side_profile
scene: scene_office_lobby
camera: camera_lobby_low_three_quarter
light: light_office_daylight
sound: sound_heel_tap
constraints: [constraint_product_fidelity, constraint_no_duplicate_shoes, constraint_office_privacy, constraint_claims_verified_only, negative_core]
variable_under_test: scene
acceptance: full_pair_visible; verified_side_profile_readable; no_extra_shoe; no_anatomy_error; no_generated_text
```

## 单条 Prompt 编译公式

```text
Mode: [mode]. [reference_roles.product]
[subject and exact product state]. [one visible task] in [scene].
Camera: [one camera move and ending frame]. Light: [one physical source]. Sound: [one sound intent].
[product fidelity + state + applicable compliance constraints].
```

删除以下内容后才可生成：第二个动作、第二个镜头、第二个产品状态、未核验细节、台词、音乐、CTA、价格、功效或性能描述。

## 单条质检

只有全部通过才可标为 `已选`：

- 鞋型、色彩、材质、鞋跟、鞋底与参考图一致。
- 产品数量与产品状态正确。
- 唯一视觉任务在前两秒可见，结束构图干净。
- 人物脚部、手部、步态和鞋与地面的接触自然。
- 无生成文字、假包装、竞品、可读办公标识、功效或性能暗示。
- 本轮唯一测试变量确实是 `[variable_under_test]`；其余变量未变。

## 成片剪辑规则

1. 从不同路线各选一条已验收片段，不强制每条都使用。
2. 成片通常使用 2–4 条原子片段；剪辑转场、品牌文字、CTA、字幕和授权音乐均在后期完成。
3. 如需续接，以上一条“已选”片段的真实末帧和观察到的状态为准，不以原始计划替代。
