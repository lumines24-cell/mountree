# 对镜拍路线生产规范

> 对镜拍的唯一目的：让目标用户在真实的出门前瞬间看清“整体穿搭与鞋的关系”。它不是产品特写、开箱或口播。先锁定镜面物理，再锁定上脚的一双，最后选择一个普通动作。

## 路线边界

| 必须有 | 不可出现 |
| --- | --- |
| 一面全身镜、一位人物、一部手机、一双上脚的参考鞋 | 第二机位、直接自拍视角、镜中镜、第二个人、手持鞋、鞋盒、跳切、口播、生成文字 |
| 手机在镜中自然可见 | 手机遮挡鞋、脚尖或大半张脸 |
| 普通出门前动作 | 跑跳、夸张摆拍、性能演示、功效或性能话术 |

## 对镜拍专属变量调用顺序

`format_mirror_selfie → product_reference_exact → product_state_worn_pair_only → persona / wardrobe → mirror scene → 一个动作或一个鞋款时刻 → mirror camera → light / room tone → continuity_mirror_reflection_lock → mirror constraints → negative_core`。

不可调用：`product_state_single_held_shoe_only`、`product_state_boxed_pair_only`、`action_hold_shoe_rotate`、`action_hold_pair_matching`、任何开箱变量、任何台词或 CTA。

## 三个叶子生成单元

| 叶子单元 | 时长 | 唯一任务 | 固定变量 | 唯一可测试变量 |
| --- | ---: | --- | --- | --- |
| `atomic_mirror_outfit_hold` | 5 秒 | 全身穿搭与一双鞋同时清楚 | `camera_mirror_phone + constraint_mirror_complete_feet` | 场景或穿搭 |
| `atomic_mirror_toe_profile` | 4 秒 | 双鞋完整入镜，完成一次脚尖前伸或轻微转踝 | `camera_mirror_low_angle + constraint_mirror_shoe_safe_frame` | 鞋款时刻 |
| `atomic_mirror_departure_check` | 5 秒 | 调整包带后停留，保留出门前真实感 | `camera_mirror_phone + action_adjust_tote` | 场景或开场动作 |

## 叶子单元的固定骨架（完整有序版）

> 从第 1 个到最后一个变量按编译顺序排列。固定项不可换；可变项每个槽位只选 1 个（动作槽位可组 2 个动作链）。对照 [[02_提示词与生成/02_视频提示词/00_变量索引\|00_变量索引]] fit 枚举。

```yaml
mirror_required:  # 对镜拍完整有序骨架
  # ── 第 1 层 规格与格式（固定）──
  - spec_tiktok_reels_short
  - format_mirror_selfie
  # ── 第 2 层 产品锚点与状态（固定）──
  - product_reference_exact
  - product_state_worn_pair_only
  # ── 第 3 层 人物（4 选 1，默认 persona_professional_woman）──
  #   候选: [persona_office_commuter, persona_editorial_commuter, persona_creative_media]
  #   人物锚定（预留）: 固定人物后改用 [[17_人物参考]] 的 persona_ref_* + persona_reference_lock
  #     （persona_* 与 persona_ref_* 互斥，同一配方只用一种）
  - persona_professional_woman
  # ── 第 4 层 穿搭（wardrobe 5 选 1，或服装参考图 outfit_ref 5 选 1）──
  - one_wardrobe_variable
  #   wardrobe 候选: [wardrobe_neutral_workwear, wardrobe_desk_to_dinner,
  #     wardrobe_neutral_blazer_trouser, styling_tailored_trousers, wardrobe_gallery_minimal]
  #   outfit_ref 候选: [outfit_ref_office_blazer, outfit_ref_midi_dress_coat,
  #     outfit_ref_linen_set, outfit_ref_white_shirt_skirt, outfit_ref_gallery_minimal]
  # ── 第 5 层 场景（12 选 1）──
  - one_mirror_scene
  #   候选: [scene_elevator_residential, scene_apartment_entryway_morning,
  #     scene_walk_in_wardrobe, scene_apartment_bedroom_oak, scene_wardrobe_window,
  #     scene_dressing_area_ivory, scene_floor_mirror_ivory_rug, scene_gallery_evening,
  #     scene_moss_garden_path, scene_pine_veranda, scene_sage_wall_entryway]
  # ── 第 6 层 动作或鞋款时刻（10 选 1；可组 2 个动作链 a → b）──
  - one_action_or_one_shoe_moment
  #   opening_action: [action_shift_weight, action_adjust_tote,
  #     action_smooth_trouser_cuff, action_half_turn]
  #   shoe_moment: [moment_toe_forward, moment_side_profile, moment_heel_down,
  #     action_step_to_mirror, action_calf_raise_hold]
  #   mirror_action: [action_ankle_turn_tap_stepback]
  # ── 第 7 层 机位（4 选 1）──
  - one_mirror_camera
  #   候选: [camera_mirror_phone, camera_mirror_low_angle,
  #     camera_top_down_floor_mirror, camera_full_look_then_shoe]
  # ── 第 8 层 光线（4 选 1）──
  - one_light_variable
  #   候选: [light_morning_window, light_elevator_practical,
  #     light_late_morning_home, light_window_diffused_editorial]
  # ── 第 9 层 声音（2 选 1）──
  - one_room_tone
  #   候选: [sound_elevator_room_tone, sound_window_room_tone]
  # ── 第 10 层 目标与钩子（可选，最多 1）──
  #   候选: [goal_shoe_silhouette, goal_outfit_finish, hook_outfit_finish]
  # ── 第 11 层 连续性（固定）──
  - continuity_mirror_reflection_lock
  # ── 第 12 层 约束（固定 + 按叶子单元二选一）──
  - constraint_product_fidelity
  - constraint_mirror_single_reflection
  - constraint_mirror_worn_pair_phone_only
  - constraint_mirror_complete_feet   # 全身单元；鞋侧面单元换 constraint_mirror_shoe_safe_frame
  - constraint_claims_verified_only
  - negative_core
```

按叶子单元再追加：全身穿搭用 `constraint_mirror_complete_feet`；鞋侧面用 `constraint_mirror_shoe_safe_frame`。

## 单条 Prompt 编译公式

```text
Mode: I2V or R2V. Use @Image1 as the exact Mountree shoe product reference only.
Vertical 9:16, one real full-length mirror reflection. [persona] in [wardrobe] at [mirror scene], wearing exactly one matching referenced pair from first frame.
[one action or shoe moment]. Camera: [one mirror camera]. Light: [one physical light]. Sound: [one room tone].
[mirror continuity and mirror constraints]. No dialogue, text, CTA, product-effect or performance claims.
```

## 对镜拍质检

- 第一秒即能读到一双鞋或完整穿搭；不得只见上半身。
- 镜中只有一个连续的人物反射；手机、左右方向、镜面和光线逻辑正常。
- 两只鞋始终是同一参考鞋的一双；鞋头、鞋跟、鞋底边缘没有被裁切或变形。
- 一条片段只有一个动作；镜头不切换，不从全身突然跳到局部特写。
- 无鞋盒、手持鞋、假 Logo、假文字、功效或性能暗示。

## 当前优先测试次序

1. `atomic_mirror_departure_check`：电梯 vs 公寓衣帽间；动作、机位、鞋和人物固定。
2. `atomic_mirror_toe_profile`：脚尖前伸 vs 轻微转踝；场景、机位、鞋和人物固定。
3. `atomic_mirror_outfit_hold`：西装裤 vs 通勤裙装；场景、机位、鞋和动作固定。

TikTok 优先看首秒双鞋可读和动作自然度；Reels 从全身穿搭或清晰鞋侧面中选一帧作为封面。品牌文案、CTA 与音乐均在后期添加。
