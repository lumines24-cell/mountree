# 开放图片提示词资料库

> 本页连接桌面的本地提示词资料库。它用于检索真实案例的画面结构，再重写为 Mountree 专属生成提示词；不是可直接商用的图片素材库。

## 本地资料

- 桌面文件夹：`Open-Image-Prompts_2026-07-25`
- `提示词/prompts.db.gz`：原始只读检索数据库
- `提示词/提示词总表_含视觉标签.csv`：14,693 条提示词、作者、来源、生成工具与视觉标签
- `图片/`：预留为已获授权、适合本地参考的图片目录
- `源数据/`：公开项目源码和本地检索工具

## 如何接入 Mountree 工作流

1. 在 CSV 中按 `visual_labels` 筛选 `产品 / 电商 / 时尚人物 / 办公室或工作区 / 自然日光 / 优雅 / 低饱和` 等组合。
2. 读取案例的构图、灯光、镜头、比例和负面限制；不要照搬产品或品牌事实。
3. 按现有分类改写并存入：
   - [[02_提示词与生成/01_图片提示词/01_按拍摄方式/01_电商产品静物提示词\|01_电商产品静物提示词]]
   - [[02_提示词与生成/01_图片提示词/01_按拍摄方式/02_生活方式与主视觉提示词\|02_生活方式与主视觉提示词]]
   - [[02_提示词与生成/01_图片提示词/01_按拍摄方式/03_对镜与穿搭提示词\|03_对镜与穿搭提示词]]
   - [[02_提示词与生成/01_图片提示词/01_按拍摄方式/04_上脚与手持提示词\|04_上脚与手持提示词]]
   - [[02_提示词与生成/01_图片提示词/01_按拍摄方式/05_开箱与用户内容提示词\|05_开箱与用户内容提示词]]
   - [[02_提示词与生成/01_图片提示词/01_按拍摄方式/06_场景封面与概念提示词\|06_场景封面与概念提示词]]
4. 生成时固定真实鞋款参考图，按 [[02_提示词与生成/01_图片提示词/01_按拍摄方式/00_图片提示词索引#每条 Prompt 末尾都加\|00_图片提示词索引#每条 Prompt 末尾都加]] 的规则避免产品漂移和虚构主张。

## 使用与权利边界

- 数据中的原始图片、提示词、作者帐号与来源链接仍属于各自权利人；只作研究、检索和提示词结构参考。
- 不将原图直接用于 Mountree 官网、广告、TikTok、商品页或印刷品。
- 仅当逐张确认授权、来源和用途后，才将图片导入 Obsidian 的分类图库。
