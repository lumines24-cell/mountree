# 提示词与穿搭内容库

完整文字资料已按“图片提示词”和“穿搭资料”分类写入 Vault 顶层的「外部文字内容库」目录。内容以 Markdown 正文展开，不依赖 CSV、JSON、仓库或附件链接。

其中包含：

- 全量图片提示词正文与分类资料；
- 女装、男装、童装的穿搭场景文字；
- 外套、上衣、下装、包、配饰与鞋类的标签文字；
- 可直接抽取的画幅、难度、场景、季节、场合、风格、廓形、材质、色彩与细节字段。

## 穿搭拆解字段

```text
场合 → 季节 → 风格 → 外套/上衣/下装 → 鞋 → 包/配饰 → 廓形 → 色彩 → 材质 → 画面动作
```

常见可复用组合：

| 内容方向 | 造型逻辑 | 适合鞋款呈现 |
| --- | --- | --- |
| 高级通勤 | 长款大衣 + 简洁内搭 + 直筒/阔腿下装 + 手袋 | 鞋型侧面、行走时的稳定感、办公室入口 |
| 都市极简 | 黑白灰或米咖低饱和 + 干净线条 + 少量金属 | 鞋面材质、鞋头比例、脚踝线条 |
| 温柔知性 | 米白、浅卡其、棕色 + 针织/柔软面料 + 半裙 | 门厅出门、咖啡店、窗边坐姿 |
| 轻复古学院 | 针织、格纹、半裙、乐福鞋/短靴语境 | 鞋款与袜子、裙长和鞋筒比例 |

## 图片提示词骨架

```text
[画幅] editorial fashion photograph of [人物原型] wearing [完整穿搭] and the attached Mountree shoe reference, in [场景 + 时间].

[唯一动作] so the shoe is clearly visible in [画面位置].
[机位 + 构图] with [光线 + 色彩].

Preserve the exact Mountree shoe silhouette, toe shape, heel height, sole pattern, color and material finish.
Negative: readable logos, copied third-party branding, product drift, warped shoes, warped feet, extra limbs, generated text, watermark.
```

## 收录原则

- 资料文件用于检索与拆解，不直接将其中人物、品牌标识或配图用于商业发布。
- 先锁定鞋款真实参考，再从穿搭表选择一个场合、一套色彩与一个造型轮廓。
- 每张图只突出一个产品时刻：上脚、迈步、坐姿鞋面或手持细节。
