# WUDASHU 产品与技术

## 产品定位

WUDASHU 产品围绕「科技舒适 + 职场女性 + 高跟鞋/通勤鞋」构建。核心品类是中国气垫缓震高跟鞋（沙利文认证「中国气垫缓震高跟鞋首创者」），并向通勤鞋、休闲鞋和季节鞋扩展。

产品理念：舒适不应是奢侈品，用科技与匠心打造隽永鞋履，服务于女性日常每一个优雅、自主的瞬间。

来源：品牌白皮书。系列内部 SKU、技术配置和价格边界会随上新变化，不能把所有款式视为采用同一套技术。

|---|---|---|---|---|
| 红云系列 | REDCLOUD | 商务正装、科技舒适高跟鞋 | 通勤、会议、正式商务、宴会 | 品牌核心及中高价产品 |
| 一半系列 | HALFUN | 商务休闲 | 日常通勤、轻正式 | 主力成交价带 |

- **红云系列**：行云直上，探索新境。
- **一半系列**：一半表达，恣意调频。
- **无压力系列**：轻松无拘，对话日常。

## 核心技术

来源：品牌白皮书与调研。技术效果、专利、检测及舒适性能仍应逐项核对，不能仅凭主播演示视为全部独立验证。

| 技术 | 说明 | 佐证 |
|---|---|---|
| 双层缓震系统 | 让鞋履在轻盈中保持稳健，撑起多变日常中的自在 | 品牌核心技术 |
| 气垫缓震 | 颠覆性引入缓震材料，让每一步轻盈稳健 | 「中国气垫缓震高跟鞋首创者」沙利文认证 |

| AI 足压分析 / 3D 鞋楦建模 | 从数万份亚洲女性脚型样本出发，释放双足空间、修饰脚型 | 与高校合作 |

## 产品表达方式

品牌产品表达不是以流行趋势为唯一核心，而是围绕「用户痛点 + 可视化测试」：

- 穿着高跟鞋跑步、快走或长时间站立，证明舒适；
- 弯折鞋底、按压鞋垫和鞋面，展示柔软与回弹；
- 解释鞋头空间、脚趾压力、掉跟和磨脚位置；
- 用通勤、带娃、遛狗等场景证明适用性；
- 通过「红云鞋」「气垫缓震」等系列词形成技术记忆。
