# WUDASHU 用户与场景

## 目标用户画像

来源：品牌白皮书用户画像 + 品牌详细调研。

| 维度 | 画像 |
|---|---|
| 年龄 | 25–45 岁都市女性 |
| 城市 | 北京、上海、杭州、成都等一线/新一线城市 |
| 职业 | 金融精英、国央企高管、自由职业者、新锐白领 |
| 时尚态度 | 理性挑剔，愿为设计、工艺和真实的穿着体验买单；追求质感 |
| 消费层级 | 大众中端至中高端线上女鞋 |
| 核心需求 | 好看与舒适兼得，解决累脚、磨脚、挤脚问题 |

> 品牌详细调研补充：目标用户主要为 30–45 岁女性，包括职场白领、精致妈妈和有正式/通勤穿着需求的人群。该信息来自公司公开招聘口径，与当前商品、直播话术和小红书内容场景基本一致。

## 用户规模（品牌口径）

- 白皮书称「500 万+ 女性用户的共同选择」，自创立以来陪伴 500 万女性走过蜕变之旅。
- 小红书官方账号约 28.4 万粉丝，抖音矩阵账号粉丝机械合计约 349.3 万。

> 粉丝与用户数口径差异较大，对外引用前需核实；「粉丝机械合计」不能等同于独立触达人数。

## 用户感知（白皮书口径）

- 「气垫缓震高跟鞋」行业心智 TOP1
- 92% 用户认为品质高级
- 95% 用户认为健康舒适
- 复购率超越行业水平

用户真实反馈关键词：

> 上脚舒服、颜值到位、包装精致、上班不累脚、脚底有支撑的软、走路很稳不磨脚、复购。

## 核心场景

| 场景 | 需求 | 对应产品 |
|---|---|---|
| 上班通勤 | 久站久走不累脚、专业形象 | 红云系列高跟鞋、浅口单鞋 |
| 商务/会议 | 正式、舒适、自信 | 红云系列 |
| 宴会/正式场合 | 优雅、显高、舒适 | 红云系列高跟 |
| 日常逛街 | 轻便、舒适、好看 | 无压力系列、一半系列 |
| 带娃出行 | 长时间行走、稳定 | 无压力系列 |
| 周末社交 | 时尚、自在 | 一半系列、休闲扩展 |

## 海外市场人群（计划进入）

- **韩国**：验证通勤舒适女鞋需求，渠道 Coupang。
- **东南亚**：验证轻便鞋款、短视频内容与直播转化，渠道 TikTok Shop。

> 韩国与东南亚为计划进入市场，人群画像与货盘方案尚在调研阶段，详见 [[市场研究/WUDASHU市场研究/海外市场导航\|WUDASHU海外市场导航]]。
