# Mountree 市场与客群

## 首站市场

首站：美国 / 北美市场。

重点国家：

- 美国
- 加拿大

## 市场判断

已记录数据方向：

| 维度 | 记录 |
|---|---|
| 全球女靴市场 | 约 $380 亿 |
| 北美占比 | 25% 以上 |
| 美国女靴增长 | 2026-2033 年复合增长率约 4.7% |
| 全球纯素鞋市场 | 约 $348 亿 |
| 纯素鞋增长 | 年增长约 7.9% |
| 消费者溢价意愿 | 原记录为 48%；来源与适用市场未核实，暂停作为定价依据 |

以上数据后续用于正式材料前需要再次核验来源。

## 核心客群

目标客群：

> 北美高净值女性职场通勤群体，重点覆盖高管、专业服务业、金融、法律、医疗教育和高阶商务人群。

城市方向：

- 美国一二线城市
- 加拿大部分核心城市

消费心理：

- 注重质感
- 不愿意穿廉价感女鞋
- 需要久站不累
- 愿意为舒适、设计和材料故事支付溢价
- 对“纯素 / 无动物皮革 / 环保材料”有加分认知

修订后的核心定义：

> 以舒适、优雅和职场适配为首要购买条件，同时偏好动物友好、植物基和透明材料的北美中高收入职业女性；严格纯素消费者作为高信任、高传播价值的核心种子群体。

购买理由排序：

1. 舒适与合脚
2. 专业、轻优雅的设计
3. 通勤、办公室、晚餐等多场景适配
4. 耐用、质量保证与退换便利
5. Animal-free / Vegan 价值观加分
6. 有证据支持的植物基与材料透明度

## 客群拆分

| 人群 | 占比假设 | 特征 |
|---|---:|---|
| 都市职场精英 | 38% | 律师、金融、科技、设计师 |
| 医疗教育人士 | 27% | 护士、教师、久站刚需 |
| 创意媒体人群 | 22% | 编辑、策展、内容行业、环保先锋 |
| 中产家庭用户 | 13% | 礼物消费、家庭决策者 |

以上占比是内部规划假设，不是已核验市场份额。

## Vegan 相关客群优先级

| 层级 | 商业角色 | 主要信息 |
|---|---|---|
| 舒适优先职场女性 | 最大成交人群 | 久站、通勤、稳定、合脚、一鞋多场景 |
| 环保 / 植物基关注者 | 品牌差异化人群 | 材料比例、构成、耐用测试和透明供应链 |
| Vegan-adjacent | 品牌扩展人群 | 好看舒适，同时符合 cruelty-free / 动物友好价值观 |
| 严格伦理型 Vegan | 种子与信任人群 | 整鞋动物源排查、胶水内里说明和认证范围 |
