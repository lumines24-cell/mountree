# 运镜 Prompt 模板

## 提示词 1：镜头运动设计

```text
请为这个分镜场景设计镜头运动。

场景：
[描述场景]

可选镜头运动：
- 平移
- 推镜
- 拉镜
- 跟拍
- 环绕
- 静态特写

每个镜头运动请说明：
- 为什么适合这个情绪节点
- 从哪里开始，到哪里结束
- 希望观众注意什么
```

## 提示词 2：竖屏短剧运镜指南

```text
请为一集竖屏短剧生成镜头运动指南。

限制：
- 画幅：9:16
- 单集时长：[1 / 1.5 / 2 / 3] 分钟
- 风格：[写实 / 日漫 / 3D]
```
