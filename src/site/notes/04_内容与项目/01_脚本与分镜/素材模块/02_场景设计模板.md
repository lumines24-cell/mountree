# Scene Design 提示词s

## 提示词 1：场景概念图

```text
请为一个短剧场景生成场景概念图提示词。

场景信息：
- 地点：
- 时间：
- 情绪基调：
- 出场人物：
- 关键动作：
- 视觉风格：[写实 / 日漫 / 3D]

请输出：
1. 全景提示词
2. 特写细节提示词
3. 俯视角提示词
4. 光线说明
5. 连续性注意事项
```

## 提示词 2：场景一致性指南

```text
请为这个场景地点生成一致性指南。

包括：
- 固定空间布局
- 反复出现的道具
- 光线规则
- 色彩风格
- 适合拍摄的角度
```
