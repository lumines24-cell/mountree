# 约束与合规

```yaml
id: constraint_product_fidelity
type: constraint
text: Preserve the exact silhouette, toe shape, heel height, sole pattern, color and material finish. Do not redesign or embellish the product.
fit: [all]
status: required
```

```yaml
id: negative_core
type: negative
text: no generated text, no readable logos, no watermark, no product drift, no warped shoes, no warped feet, no extra fingers, no extra limbs, no impossible anatomy, no impossible gait, no jump cuts
fit: [all]
status: required
```

```yaml
id: constraint_claims_verified_only
type: compliance
text: Do not generate product-effect or performance claims. Do not generate unverified material, environmental, certification, price, inventory or sizing claims.
fit: [all]
status: required
```

```yaml
id: constraint_no_body_anxiety
type: compliance
text: Avoid body-anxiety language; use restrained styling language such as sleek silhouette only when visually appropriate.
fit: [all]
status: required
```

```yaml
id: constraint_motion_safety
type: compliance
text: Do not portray running, jumping or balance as proof of heel performance, safety, stability or durability.
fit: [dynamic_concept, try_on]
status: required
```
