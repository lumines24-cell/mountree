# 产品锚点

> 每次生成先选一张或多张实物图；下列变量只允许描述参考图中可见的结构。

```yaml
id: product_reference_exact
type: product_anchor
text: Use the attached Mountree shoe reference exactly for the product.
fit: [all]
status: required
source: 02_视频要素库/01_产品事实与参考素材
```

```yaml
id: product_visible_toe
type: visible_detail
text: a clear toe-shape view
fit: [try_on, mirror_selfie, product_led]
status: verified_only
```

```yaml
id: product_visible_side_profile
type: visible_detail
text: the side profile and heel height
fit: [try_on, mirror_selfie, product_led]
status: verified_only
```

```yaml
id: product_visible_material_finish
type: visible_detail
text: the material finish in natural window light
fit: [unboxing, handheld, product_led]
status: verified_only
```

```yaml
id: product_no_invention
type: protection
text: Do not invent logos, text, packaging, technical features or material claims not visible in the reference.
fit: [all]
status: required
```

```yaml
id: reference_assets_only
type: asset_scope
text: Show only the shoes and packaging visibly supplied in the attached reference images. Do not add props, gift cards, ribbons, tissue-paper designs, labels, boxes, brands or materials not present in those references.
fit: [unboxing]
status: required
```

## 产品数量与状态锁定

```yaml
id: product_state_worn_pair_only
type: product_state
text: One matching pair of the referenced shoes is worn on both feet from the first frame to the final frame. No shoe is held, carried, placed on a surface, added, removed, duplicated or disappears.
fit: [ugc, mirror_selfie, try_on, situational]
status: required_when_on_foot
```

```yaml
id: product_state_single_held_shoe_only
type: product_state
text: Exactly one referenced shoe is visible in both hands; no shoe is worn on either foot and no second shoe enters the frame.
fit: [unboxing, handheld]
status: required_when_handheld
```

```yaml
id: product_state_boxed_pair_only
type: product_state
text: A matching pair of the referenced shoes rests side by side inside one open shoe box. Both shoes are visible together after the tissue paper opens; one shoe may be lifted by hand for a brief detail view while the matching shoe remains visible inside the box. Neither shoe is worn, duplicated, replaced or disappears.
fit: [unboxing]
status: required_for_unboxing
```

```yaml
id: product_state_pair_lifted_box_empty
type: product_state
text: A matching pair of the referenced shoes is lifted together from one open shoe box after the pair reveal. Both shoes remain visible as one pair in two hands; the open box is visibly empty and contains no shoe. Neither shoe is worn, duplicated, replaced or disappears.
fit: [unboxing]
status: separate_clip_only
```
