# Mountree 玉米基 30% 植物基皮料与工艺

## 当前确认事实

- 材料类型：玉米基生物基 PU 皮料。
- 植物基含量：30%。
- 使用状态：Mountree 当前批次已确定采用。
- 后续范围：所有产品、营销和材料内容以该玉米基 30% 皮料为主；其他植物来源皮料暂不推进。
- 证据管理：30% 为当前内部确认口径；对外使用前仍需把对应批次检测报告、测试方法和检测对象归档。

## 当前路线：生物基 PU 玉米皮料

工艺链条：

1. 玉米淀粉提取
2. 酶解糖化为葡萄糖
3. 微生物发酵制备生物 PDO
4. 生物 PDO + MDI + 多元醇聚合成生物基 PU 树脂
5. 离型纸涂布成革
6. 压纹、揉软、防水防污后整理
7. 耐折、耐磨、剥离强度、水解稳定性检测

优点：

- 工业量产稳定
- 耐弯折较好
- 手感接近中厚牛皮
- 制鞋厂设备改造小
- 适合乐福、牛津、德比、切尔西靴、通勤女鞋

关注指标：

- 生物基碳含量
- 耐折次数
- 耐磨
- 剥离强度
- 水解稳定性
- REACH、DMF、重金属检测

### 非当前路线：PLA 全淀粉改性材料

不属于 Mountree 当前皮料路线，暂不开发，仅保留材料辨识用途。

优点：

- 植物基含量高
- 堆肥环境下可降解潜力
- 成本较低

短板：

- 低温易脆
- 潮湿环境强度下降
- 久穿易裂
- 手感塑料感更明显

适合：

- 低频休闲鞋
- 配饰
- 非高强度弯折部件

## PDO 与 PLA 区分

PDO = 1,3-Propanediol / 1,3-丙二醇。

- 小分子醇
- 用于合成生物基 PU
- 决定柔韧、回弹和耐折性能

PLA = Polylactic Acid / 聚乳酸。

- 本身是高分子材料
- 可熔融压膜
- 更硬、更脆，耐水性和耐折较弱

简化判断：

- 玉米淀粉 → 发酵 PDO → 生物基 PU：更适合鞋面
- 玉米淀粉 → 发酵乳酸 → PLA：更适合低频、低强度应用

## Mountree 选材建议

当前只推进玉米基 30% 植物基皮料。工作重点从“比较植物来源”转为：

1. 锁定当前量产皮料的结构、树脂型号和批次。
2. 完成耐折、耐磨、耐水解、剥离、色牢度和低温性能验收。
3. 归档 30% 植物基含量的检测报告及计算口径。
4. 建立统一的产品、独立站、社媒、包装和达人 Brief 表述。

当前统一口径：

- Mountree 当前批次皮料按已确认信息记录为“玉米基，植物基含量 30%”。
- 30% 指当前皮料，不延伸为整鞋 30%；鞋底、胶黏剂、内里和辅料需分别核算。
- “源自工业玉米”不等于材料 100% 植物基，也不等于可自然降解。
- 对外宣传应采用当前量产皮料对应的检测报告，而不是只引用上游树脂的报告。

采购必须要求：

- 生物基含量检测
- 耐折测试
- 耐磨测试
- 水解测试
- 色牢度
- 剥离强度
- 鞋面开料和成型试产反馈
