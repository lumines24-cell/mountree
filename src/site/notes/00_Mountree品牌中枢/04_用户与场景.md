# Mountree 市场与客群

## 首站市场

首站：美国 / 北美市场。

重点国家：

- 美国
- 加拿大

## 市场判断

已记录数据方向：

| 维度 | 记录 |
|---|---|
| 全球女靴市场 | 约 $380 亿 |
| 北美占比 | 25% 以上 |
| 美国女靴增长 | 2026-2033 年复合增长率约 4.7% |
| 全球纯素鞋市场 | 约 $348 亿 |
| 纯素鞋增长 | 年增长约 7.9% |
| 消费者溢价意愿 | 48% 消费者愿意为无动物产品支付溢价 |

以上数据后续用于正式材料前需要再次核验来源。

## 核心客群

目标客群：

> 北美高净值女性职场通勤群体，重点覆盖高管、专业服务业、金融、法律、医疗教育和高阶商务人群。

城市方向：

- 美国一二线城市
- 加拿大部分核心城市

消费心理：

- 注重质感
- 不愿意穿廉价感女鞋
- 需要久站不累
- 愿意为舒适、设计和材料故事支付溢价
- 对“纯素 / 无动物皮革 / 环保材料”有加分认知

## 客群拆分

| 人群 | 占比假设 | 特征 |
|---|---:|---|
| 都市职场精英 | 38% | 律师、金融、科技、设计师 |
| 医疗教育人士 | 27% | 护士、教师、久站刚需 |
| 创意媒体人群 | 22% | 编辑、策展、内容行业、环保先锋 |
| 中产家庭用户 | 13% | 礼物消费、家庭决策者 |

## 定价

- 单双客单价 $79-$119
- 当前价格基准：$79-$119
- 通过舒适科技、美国专利申请、绿色材料和本土履约支撑 $79-$119 价格基准
